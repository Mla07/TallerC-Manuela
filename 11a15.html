Puntos 11–15

11) Mini–Agenda de Contactos

Objetivo: Aplicar encapsulamiento, colecciones y búsqueda.

Implementación: Contacto: Nombre, Telefono (solo dígitos, 7–15 caracteres). Agenda: métodos Agregar(), BuscarPorNombre() (sin distinguir mayúsculas), Listar().

Concepto: Ejemplo de composición: una Agenda contiene múltiples Contactos. Se aplica validación y búsqueda dentro de una colección.

classDiagram class Agenda { - List~Contacto~ contactos + void Agregar(Contacto c) + Contacto BuscarPorNombre(string nombre) + void Listar() } class Contacto { + string Nombre + string Telefono + Contacto(string nombre, string telefono) } Agenda *-- Contacto : contiene >

12) Sistema de Calificaciones por Asignatura

Objetivo: Validar propiedades y calcular promedios.

Implementación: Clase Asignatura con Nombre y arreglo Notas. Método Promedio() valida que haya al menos una nota y todas estén entre 0..5.

Concepto: Combina validación, operaciones sobre colecciones y formato de salida con precisión decimal.

classDiagram class Asignatura { + string Nombre + double[] Notas + double Promedio() } Asignatura : Valida notas entre 0 y 5

13) Inventario Simple con Invariantes

Objetivo: Mantener estado consistente y evitar valores inválidos.

Implementación: Producto: Nombre, Precio (≥0). InventarioItem: contiene un Producto, controla el Stock mediante Entrar() y Salir().

Concepto: La composición y las invariantes garantizan que el sistema no permita estados imposibles (stock negativo).

classDiagram class Producto { + string Nombre + double Precio } class InventarioItem { + Producto Producto + int Stock + void Entrar(int cantidad) + bool Salir(int cantidad) } InventarioItem *-- Producto : asocia >

14) Envío de Notificaciones (Interfaz + Polimorfismo)

Objetivo: Cambiar implementación sin modificar el cliente.

Implementación: Reusar INotificable, NotificadorEmail y NotificadorSms. Crear método estático AvisarPedidoListo(INotificable canal, string cliente).

Concepto: Demuestra el polimorfismo por interfaz: distintas implementaciones responden a la misma llamada.

classDiagram class INotificable { <> + void Enviar(string mensaje) } class NotificadorEmail { + void Enviar(string mensaje) } class NotificadorSms { + void Enviar(string mensaje) } INotificable <|.. NotificadorEmail INotificable <|.. NotificadorSms

15) Reporte de Figuras (Abstracta + Polimorfismo + Agregación)

Objetivo: Combinar herencia, polimorfismo y agregación.

Implementación: Reutilizar Figura, Circulo y Rectangulo. Crear una lista de figuras, calcular el total, el área total y la figura con mayor área.

Concepto: Ejemplo avanzado de polimorfismo, reutilización de clases y uso de colecciones para generar reportes.

classDiagram class Figura { <> + abstract double Area() + void MostrarArea() } class Circulo { + double Radio + override double Area() } class Rectangulo { + double Ancho + double Alto + override double Area() } Figura <|-- Circulo Figura <|-- Rectangulo
