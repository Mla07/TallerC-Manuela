Diagramas de Clases UML – Taller POO (Ejercicios 11–15)

11) Agenda y Contacto

classDiagram class Agenda { - List~Contacto~ contactos + void Agregar(Contacto c) + Contacto BuscarPorNombre(string nombre) + void Listar() } class Contacto { - string telefono + string Nombre + string Telefono + Contacto(string nombre, string telefono) } Agenda *-- Contacto : contiene >

Relación: Agenda tiene una relación de composición con Contacto (una agenda contiene muchos contactos). Validación: Telefono solo acepta dígitos entre 7 y 15 caracteres.

12) Asignatura y Notas

classDiagram class Asignatura { + string Nombre + double[] Notas + double Promedio() }

Concepto: Asignatura modela una materia con un arreglo de notas (0–5). El método Promedio() calcula el promedio y valida los rangos de las notas.

13) Inventario: Producto e InventarioItem

classDiagram class Producto { - double precio + string Nombre + double Precio } class InventarioItem { + Producto Producto + int Stock + InventarioItem(Producto p, int stockInicial) + void Entrar(int cantidad) + bool Salir(int cantidad) } InventarioItem *-- Producto : asocia >

Relación: InventarioItem tiene una composición con Producto. Controla el stock e impide cantidades negativas.

14) Envío de Notificaciones (Uso de Interfaces)

classDiagram class INotificable { <> + void Enviar(string mensaje) } class NotificadorEmail { + void Enviar(string mensaje) } class NotificadorSms { + void Enviar(string mensaje) } INotificable <|.. NotificadorEmail INotificable <|.. NotificadorSms

Concepto: Muestra el uso del polimorfismo por interfaz. Ambas clases implementan el mismo contrato y se pueden usar indistintamente donde se requiera un INotificable.

15) Reporte de Figuras (Herencia Abstracta)

classDiagram class Figura { <> + double Area() + void MostrarArea() } class Circulo { + double Radio + double Area() } class Rectangulo { + double Ancho + double Alto + double Area() } Figura <|-- Circulo Figura <|-- Rectangulo

Concepto: Figura actúa como clase abstracta. Las subclases Círculo y Rectángulo implementan el método Area() según su fórmula geométrica. Este ejercicio demuestra abstracción y reutilización.
