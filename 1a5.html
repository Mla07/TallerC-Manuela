Diagramas de Clases UML – Taller POO (Ejercicios 1–5)

1–2) Clase Persona (Propiedades y Constructor)

classDiagram class Persona { - string nombre - int edad + Persona() + Persona(string nombre, int edad) + void Saludar() }

Descripción: La clase Persona modela un individuo con nombre y edad, y un método que imprime un saludo. Se incluyen dos constructores: uno vacío y otro con parámetros.

3–4) Persona con Encapsulamiento y Propiedad Calculada

classDiagram class Persona { - int edad + string Nombre + int Edad + bool EsMayorDeEdad + void Saludar() }

Notas UML: Edad aplica validación (0–120). EsMayorDeEdad es una propiedad calculada: retorna true si la edad ≥ 18.

5) Clase CalculadoraBasica

classDiagram class CalculadoraBasica { + static int ConteoOperaciones + double Sumar(double a, double b) + double Restar(double a, double b) + double Multiplicar(double a, double b) + double Dividir(double a, double b) }

Descripción: Clase con métodos aritméticos básicos. Cada operación incrementa un contador estático ConteoOperaciones.
