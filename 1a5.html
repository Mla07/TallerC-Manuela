Taller de Programación Orientada a Objetos
Guía Explicada: Puntos 1–5

1) Clase mínima: Persona

Este primer ejercicio es la base para entender qué es una clase y cómo crear un objeto.

Una clase es como un molde: define qué datos (propiedades) y qué comportamientos (métodos) tendrá el objeto. En este caso, la clase Persona tiene dos propiedades simples: Nombre y Edad.

Ejemplo mental: imagina una ficha de persona con dos espacios para escribir su nombre y su edad. Cuando creas un objeto, es como llenar una ficha específica.

Además, implementamos un método Saludar() que muestra un mensaje personalizado. Al crear dos instancias (por ejemplo Ana y Luis) y llamar al método, cada una muestra su propio saludo.

Aprendizaje clave: una clase es un molde, un objeto es una copia real con datos propios.

classDiagram class Persona { + string Nombre + int Edad + void Saludar() } Persona : Hola, soy {Nombre} y tengo {Edad} años

2) Constructor básico en Persona

Ahora se introduce el concepto de constructor: un método especial que se ejecuta automáticamente al crear un objeto.

El constructor permite inicializar los datos desde el momento en que se crea la instancia, evitando tener que asignarlos después.

Ejemplo: Persona p = new Persona("Ana", 20); Esto crea un nuevo objeto y le da nombre y edad en una sola línea.

Los constructores ayudan a garantizar que todos los objetos empiecen con un estado válido.

Aprendizaje clave: los constructores facilitan la inicialización y mantienen la coherencia de los objetos.

classDiagram class Persona { + string Nombre + int Edad + Persona() + Persona(string nombre, int edad) + void Saludar() }

3) Encapsulamiento con validación

Este punto presenta un concepto esencial: el encapsulamiento.

Encapsular significa proteger los datos internos de una clase para evitar que se modifiquen de manera incorrecta.

Se logra usando propiedades (get y set) que controlan cómo se accede o modifica un valor.

Por ejemplo, si alguien intenta asignar una edad negativa, el programa no lo permite: Edad = -5 → lanza una excepción con un mensaje claro.

Esto asegura que los objetos siempre estén en un estado válido. Si algo falla, se usa un bloque try/catch para manejar el error sin detener el programa.

Aprendizaje clave: el encapsulamiento protege los datos y mejora la seguridad del código.

classDiagram class Persona { - int edad + string Nombre + int Edad + void Saludar() } Persona : Validar Edad entre 0 y 120

4) Propiedad calculada: EsMayorDeEdad

Aquí aprendemos la diferencia entre un dato almacenado y un dato calculado.

La propiedad EsMayorDeEdad no guarda un valor; lo calcula en tiempo real basándose en la Edad.

Ejemplo: Si Edad = 20, entonces EsMayorDeEdad devuelve true.
Si Edad = 16, devuelve false.

Así no hay duplicación de datos ni riesgo de inconsistencia. Si cambia la edad, el resultado de EsMayorDeEdad también cambia automáticamente.

Aprendizaje clave: las propiedades calculadas derivan información en tiempo real sin almacenarla.

classDiagram class Persona { + string Nombre + int Edad + bool EsMayorDeEdad + void Saludar() } Persona : EsMayorDeEdad => Edad >= 18

5) Métodos con parámetros y retorno: CalculadoraBasica

Este ejercicio introduce los métodos que reciben parámetros y devuelven resultados.

La clase CalculadoraBasica tiene métodos para sumar, restar, multiplicar y dividir números.

Ejemplo: Sumar(3, 5) devuelve 8. Dividir(10, 0) lanza una excepción, pero el programa la maneja sin fallar.

También se aprende que no todo método imprime resultados: algunos devuelven valores para ser usados en otros cálculos.

Aprendizaje clave: los métodos son las acciones de una clase; pueden procesar datos y devolver información útil.

classDiagram class CalculadoraBasica { + double Sumar(double a, double b) + double Restar(double a, double b) + double Multiplicar(double a, double b) + double Dividir(double a, double b) } CalculadoraBasica : Valida divisor != 0
