7–8) Herencia y Polimorfismo: Vehículo, Auto y Bicicleta

classDiagram class Vehiculo { + string Marca + void Arrancar() + string Describir() } class Auto { + int Puertas + string Describir() } class Bicicleta { + bool TieneCanastilla + string Describir() } Vehiculo <|-- Auto Vehiculo <|-- Bicicleta

Relaciones: Auto y Bicicleta heredan de Vehiculo y sobreescriben el método Describir(). Polimorfismo: permite tratar ambos objetos como Vehiculo y obtener comportamientos diferentes.

9) Interfaz INotificable y sus implementaciones

classDiagram class INotificable { <> + void Enviar(string mensaje) } class NotificadorEmail { + void Enviar(string mensaje) } class NotificadorSms { + void Enviar(string mensaje) } INotificable <|.. NotificadorEmail INotificable <|.. NotificadorSms

Concepto: Las interfaces definen un contrato. Ambas clases implementan INotificable y proporcionan su propia forma de enviar mensajes (email o SMS).

10) Clases abstractas: Figura, Círculo y Rectángulo

classDiagram class Figura { <> + double Area() + void MostrarArea() } class Circulo { + double Radio + double Area() } class Rectangulo { + double Ancho + double Alto + double Area() } Figura <|-- Circulo Figura <|-- Rectangulo

Concepto: Una clase abstracta define una base común sin implementación completa. Círculo y Rectángulo heredan de Figura e implementan Area() según su forma geométrica.
